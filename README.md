# Full Stack E-Commerce Project

## Overview

This is a Full Stack E-Commerce Web Application built using React.js, Node.js, Express.js and MongoDB.

## Features

- Product Listing
- Product Search
- Category Filter
- Shopping Cart
- Wishlist
- Product Rating
- Add Product
- Edit Product
- Delete Product

## Tech Stack

Frontend:
- React.js
- Bootstrap

Backend:
- Node.js
- Express.js

Database:
- MongoDB
