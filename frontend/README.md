# Full Stack E-Commerce Project

## Overview

This is a Full Stack E-Commerce Web Application developed using React.js, Node.js, Express.js, and MongoDB.

## Features

- Product Listing
- Product Details Page
- Product Search
- Category Filter
- Shopping Cart
- Wishlist
- Product Rating
- Review System
- Add Product
- Edit Product
- Delete Product

## Tech Stack

### Frontend
- React.js
- Bootstrap
- React Router

### Backend
- Node.js
- Express.js

### Database
- MongoDB

## Installation

### Frontend

```bash
cd frontend
npm install
npm start
```

### Backend

```bash
cd backend
npm install
npm start
```
